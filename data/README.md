# Agricultural training corpus

`raw/agriculture.jsonl` contains a small starter corpus with crop, topic, advice text and source attribution. It currently covers rice, maize, wheat and tomato.

The corpus is intentionally conservative and educational. Do not treat model-generated text as a prescription for pesticide, fertilizer or disease treatment. Extend the corpus only with trusted, current, region-specific agricultural publications and retain the source URL and publication/update date for every record.

Primary references used for this starter set:
- TNAU Agritech Portal: https://agritech.tnau.ac.in/
- ICAR Kharif Agro-Advisories for Farmers 2025: https://icar.gov.in/sites/default/files/Circulars/ICAR-En-Kharif-Agro-Advisories-for-Farmers-2025.pdf
