# Crop Advice Snippet AI

A command-line tool that gives short, crop-specific agricultural advice. It combines a small GPT model trained from scratch on farming text (byte-pair tokenizer, embeddings, causal self-attention) with a crop registry, a disease and pest database, weather and soil checks, and a records store.

## Quick start

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python tools/generate_crop_registry.py   # builds data/crops/crop_registry.json
python -m tools.seed_sample_records      # writes two sample tomato records
pytest -q
python -m app.cli hello
```

On Windows PowerShell, activate with `.\.venv\Scripts\Activate.ps1` and copy the environment file with `Copy-Item .env.example .env`.

## Example commands

```bash
python -m app.cli advice --crop Tomato --problem "early blight"
python -m app.cli crops search --query mango
python -m app.cli records list --crop tomato
```

Example output from `advice`:

```
[*] CROP ADVICE SNIPPET AI: TOMATO
Issue/Problem : early blight
Advice Snippet:
Remove infected leaves and apply a copper-based fungicide at first symptoms of early blight.
```

## Limitations

- Advice comes from stored records. The bundled sample has only two tomato records, so most crops and problems return no advice yet.
- The GPT model is trained from scratch on a small corpus. No accuracy or evaluation has been run, so none is claimed.
- The crop registry is generated by `tools/generate_crop_registry.py` from hand-entered data. Its agronomic details have not been independently checked.
- This is a learning project. Check any advice with a local agronomist before acting on it.

## Settings and secrets

Model settings live in `.env`, which is ignored by git. Never commit `.env` or paste a key into code. If a key ever reaches GitHub, treat it as leaked and make a new one.

## Stretch ideas

- Curate a larger and more diverse agricultural dataset.
- Let users add soil type, weather, and growth stage to tailor advice. The CLI already accepts these options; the next step is to measure whether they change the output.
- Add a feedback command so users can rate advice.

## Origin

This project started from a course starter template, which provided the milestone structure, the CI workflow, and the test scaffolding. The crop registry data, disease and pest database, records store, weather and soil checks, and CLI commands were written for this project.

## Evaluation

- **Automated tests:** 20 tests cover the CLI, the crop registry, the records store, and the tokenizer and embedding code. They run on every push in GitHub Actions.
- **Model accuracy:** not measured yet. The `advice` command returns stored records, so its output does not show how well the GPT model performs. Measuring the model would mean training it with `python -m app.cli train` and scoring its answers to a fixed set of questions. That has not been done.
